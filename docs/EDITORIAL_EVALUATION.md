# 摘要选材与质量复测

格式合法、来源代号存在，不代表摘要有用或事实正确。提示词变更应同时检查选材、事实归属、条件完整性与展示；不能用返回固定答案的模拟模型证明语义质量。

## 选材标准

每个要点应给目标读者带来具体的信息增量：增进对问题的理解、改进方法、帮助作出选择或避开风险。知识解释和长期经验不必能立即指导行动。结合当期讨论判断，不将短期热点固化为长期收录范围或类别优先级。话题热度、学校名气、履历数字的多少都不是收录依据；小众但有明确用途的信息也可以保留。

| 内容 | 预期 |
| --- | --- |
| 一次实验复现排查中发现随机数据划分造成差异，并给出固定划分清单的方法 | 保留具体问题、方法与适用条件，不要求与当期招生相关 |
| 解释梯度累积遇到 BatchNorm 时为何不等价于一个大批次 | 保留有助理解的解释，不因没有立即行动项而舍弃 |
| 本人实习协议中明确的退出条件及后果 | 保留具体批次、来源和限制，不推广到公司全部协议 |
| 某本科第一名去了名校，附成绩、论文、竞赛清单 | 默认舍弃；仅有结果和履历不是申请方法或录取门槛 |
| 听说某学院卡 rk1 / 只收双一流 | 保留具体说法、署名和不确定性，不要求官方核实 |
| 四非本人收到了上述学院某方向的面试通知 | 保留为相关反例；面试不等于录取，不替读者裁定通用政策 |
| 明确学院、培养类型和截止时间的招生通知 | 有效窗口保留条件、时间和原链接；过期通知不写成仍可报名 |
| 同一发言者随后明确更正截止时间 | 采用更正后的时间，不能丢掉未变的条件 |
| 某学院候补第 23 名收到递补电话 | 保留个人进展；不推导官方候补线或仍有空余名额 |
| 只有“23 捞到我了”，对象或数字口径不明 | 舍弃；不能从昵称猜学校或自行补成分数/名次 |
| 面试口头承诺后反悔，已填志愿无法退回 | 保留亲历流程和风险；不补写撤销原因 |
| “某校还招吗？”“看看/试试呗” | 舍弃；回答了不等于有实质信息 |
| 有用条目中夹带“羡慕”“天花板”“有书读了” | 只删无用要点，保留真正有用的部分 |
| 通知正文只在不可见的图片、附件或网页中 | 不推断；不可见媒体占位不是读者需要的摘要要点 |
| 全部是报喜、互夸、空泛评价和无答案提问 | 返回空 `items`，不能为了填满上限编写建议 |

## 对照方法

1. 固定原始消息、时间窗口、回复关系、任务配置与模型设置。修改提示词时记录完整版本，关闭模型结果缓存，复用相同的历史输入。
2. 至少对照原版与候选版。先用涵盖不同话题的合成边界样例，再用包含真实噪声的完整时间窗口；短样例通过不能替代长上下文检查，也不能只测试当前最热的单一话题。
3. 逐条回查源消息及明确回复：学校/学院、事件、人物、数字口径、截止时刻、不确定性、本人更正、原始链接。发言者相同或消息相邻不代表同一话题。
4. 记录漏掉的关键机会、混入的低价值要点、错误归属和无依据建议，不能仅用主题数、字数或模型自己的评分比较。
5. 用另一时间窗口复测最终候选，再运行无发送的预览接口，核对正式排版。合并转发可本地检查载荷，无需把实验发进真实群。
6. 保留调用次数、实际 usage、耗时与输出。原始群聊、昵称、群号、配置及凭据只保存在本地，不提交公开仓库。不要保存模型思考正文。

## 局限

同一模型、相同提示词的输出仍可能不同。长记录中的交错话题、缩写、多人的相互回应会增加混淆风险；增加规则或例子也不保证更好。少写几条不是质量提升的充分证据。

本插件继续优先一次模型调用，不增加固定的第二次“自评”请求，也不以学校名单或关键词硬过滤个人案例。当前本地校验检查格式、预算和来源代号范围，不能证明每句都得到原文支持。实际发布质量应以上述逐项源文检查和自己的预览为准。
